# پرش (PareshCrowd): پروتوتایپ رابط کاربری

پروتوتایپ استاتیک، راست‌به‌چپ و ریسپانسیو سکوی تأمین مالی جمعی **پرش**. برای اجرا به build نیاز ندارد.

## اجرا

یکی از فایل‌های HTML را مستقیم در مرورگر باز کنید، یا یک سرور محلی اجرا کنید:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

| صفحه | فایل |
| --- | --- |
| صفحه اصلی | `index.html` |
| لیست طرح‌ها (فیلتر و مرتب‌سازی) | `plans.html` |
| جزئیات طرح | `plan.html?id=saffron-pack` (شناسه‌ها در `assets/js/data.js`) |
| سیستم طراحی (توکن‌ها و کامپوننت‌ها) | `styleguide.html` |

## ساختار

```
assets/css/fonts.css       @font-face فونت مدام (اعداد فارسی)
assets/css/tokens.css      رنگ، تایپوگرافی، فاصله‌گذاری، شعاع، سایه، حرکت
assets/css/base.css        ریست، تایپوگرافی پایه، گرید، ابزارها
assets/css/components.css  هدر، دکمه، نشان، کارت طرح، پیشرفت، ریسک، فرم، تب، آکاردئون، فوتر
assets/css/pages.css       بخش‌های هر صفحه
assets/js/data.js          داده نمونه طرح‌ها (همه اعداد فرضی است)
assets/js/main.js          رندر کارت‌ها، ماشین‌حساب سود، فیلترها، جدول پرداخت، انیمیشن‌ها
assets/fonts/modam/        فونت مدام (woff2 و woff)
assets/img/logo.svg        نشانه پرش (بازسازی تقریبی از برندبوک)
```

## تصمیم‌های طراحی

- **رنگ**: فقط از Color Sheet نسخه اوت ۲۰۲۶.
  - کرم `#EFEEE7` پس‌زمینه، سفید برای کارت‌ها، صورتی `#F6D7CF` برای سطوح گرم، سرمه‌ای `#0E1938` برای متن و بخش‌های تیره.
  - آبی `#0068FF` فقط برای اکشن (دکمه اصلی، لینک، فوکوس).
  - سبز `#0EA665` برای سود و پیشرفت، مرجانی `#F9564D` برای ریسک و هشدار، لیمویی `#A3E96B` برای هایلایت روی سرمه‌ای.
  - گرادیان ثانویه (مش رنگی) فقط یک بار، پشت ماشین‌حساب سود، استفاده شده است.
- **لحن**: مطابق برندبوک، «وضوح، نه وعده».
  - هر کارت طرح، سود را کنار ضمانت و سطح ریسک نشان می‌دهد.
  - صفحه هر طرح بخشی با عنوان «چه چیزهایی ممکن است خوب پیش نرود؟» دارد.
  - همه‌جا تأکید شده که سود «پیش‌بینی‌شده» است.
- **پویایی برای مخاطب ۲۵ تا ۴۰ سال**:
  - کپسول درناها، برگرفته از کاور Color Sheet، همراه با کارت‌های شناور.
  - شمارنده‌های آماری، پر شدن نوار پیشرفت و ظاهر شدن بخش‌ها هنگام اسکرول.
  - همه انیمیشن‌ها به تنظیم `prefers-reduced-motion` احترام می‌گذارند.
- **بنچ‌مارک‌ها (زیما، یکتاکراد)**:
  - از آن‌ها گرفته‌ایم: فیلدهای استاندارد هر طرح (سود، مدت، دوره پرداخت، ضمانت، پیشرفت جذب)، آمار تجمیعی، مجوز فرابورس و جدول سررسید پرداخت‌ها.
  - تفاوت پرش: چیدمان خلوت‌تر و شفافیت ریسک.

## نکات

- فونت **مدام** تجاری است (fontiran.com). فقط در ریپوی خصوصی نگه داشته شود و پیش از انتشار عمومی، لایسنس وب آن تهیه شود.
- لوگو تقریبی است. فایل وکتور رسمی را جایگزین `assets/img/logo.svg` و SVGهای داخل هدر و فوتر کنید.
- همه اعداد، طرح‌ها و شرکت‌ها نمونه و فرضی است.
